# AI Weekend: werkmap

Werkmap van Eghosa voor de Branding Agent van Revenue Lab. `CLAUDE.md` bevat de gedeelde regels, `04-branding-agent/` het plan
(`CLAUDE.md`), de analyse van de bestaande systemen (`ANALYSE.md`) en de voortgang (`VOORTGANG.md`). De code komt in de
bestaande repo's.

## Starten op een (andere) laptop

```sh
cd ~/Developer
git clone https://github.com/Eghosag1/ai-weekend.git AI-Weekend
```

Kloon de repo's uit de tabel in `CLAUDE.md` naast deze map. Werken: open Claude Code in deze map en geef de repo erbij met
`--add-dir`, bv. `claude --add-dir ../revenuelab-portaal`.

Begin elke sessie met `git pull` en eindig met commit + `git push`.

## Inhoud

- `CLAUDE.md`: gedeelde regels en waar de code staat.
- `00-bronnen/`: de briefing voor de branding agent en de oorspronkelijke briefing.
- `04-branding-agent/`: plan, analyse en voortgang.

De andere onderdelen (01 tot 10, `_thibo`) zijn op 21/11 uit deze werkmap gehaald; laatste stand met alles: commit `f482e06`.
